# тихо ♥ — сайт для признания в любви

Светлая адаптивная страница с тремя вопросами и необязательным сообщением. Ответы сохраняются на сервере, а отправитель не вводит имя или контакты.

## Секретные ссылки
- `/s/<PUBLIC_TOKEN>` — страница признания для получателя.
- `/inbox/<INBOX_TOKEN>` — ваши входящие ответы. Не передавайте эту ссылку другим.

Токены должны быть разными, случайными и не короче 24 символов. Создать их в терминале:
```sh
export PUBLIC_TOKEN="$(node -e "console.log(require('crypto').randomBytes(24).toString('hex'))")"
export INBOX_TOKEN="$(node -e "console.log(require('crypto').randomBytes(24).toString('hex'))")"
npm start
```
Сайт локально будет на `http://localhost:3000`. Секретные ссылки можно вывести командами:
```sh
echo "Ссылка признания: http://localhost:3000/s/$PUBLIC_TOKEN"
echo "Ответы: http://localhost:3000/inbox/$INBOX_TOKEN"
```

## Публикация
Нужен Node.js-хостинг, запускающий `npm start`, с HTTPS и постоянным хранилищем для файла `messages.json`. Задайте `PUBLIC_TOKEN`, `INBOX_TOKEN` и при необходимости `DATA_FILE` через переменные окружения хостинга. Если хостинг очищает локальные файлы при перезапуске, ответы могут пропасть; проверьте условия хранения до публикации.

## Приватность и ограничения
Сайт не просит имён, контактов или геолокации и не подключает аналитику. Однако провайдер хостинга может обрабатывать IP-адреса и вести технические журналы. Секретная ссылка может быть переслана, поэтому это не абсолютная защита. Входящие доступны по отдельной секретной ссылке; храните её приватно. Встроенный лимит отправки — базовый, для большой публичной аудитории нужна отдельная защита от спама.
